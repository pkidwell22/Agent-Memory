# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for a suspected vulnerability or include
credentials, private file paths, vault contents, or other sensitive data in a
report.

Use GitHub's private vulnerability reporting from the repository's Security
tab. Include the affected version, reproduction steps, impact, and a minimal
proof of concept when possible.

You should receive an initial response within seven days. Please allow time for
a fix to be prepared before publicly disclosing the issue.
